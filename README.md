# 临沂物流 TMS 运输管理系统（教学演示）

位于山东省临沂市的第三方物流企业运输管理系统（TMS）教学演示网页应用，用于课堂教学，演示山东省内城际干线 + 临沂本地城配全流程。

## 功能模块

- **仪表盘首页**：总运单数、在途车辆、待调度/异常运单、近 7 天发车到货趋势、未来一周线路需求预测
- **运单受理与调度**：新建运单（临沂发山东 16 地市）、调度指派空闲车辆、高速/国道两种运输方式
- **运输执行管理**：待调度 → 已指派 → 已发车在途 → 待签收 → 已完成 五步状态流转
- **在途监控地图**：山东省真实行政边界 + 高速/国道路网，10 辆卡车实时沿路网行驶，可缩放/平移/点击查看车辆详情
- **到货签收与回单**：录入签收人、回单状态、异常记录（高速封路/货损/温控异常/拒收）
- **历史数据查询**：近 30 天运单明细，多条件筛选
- **使用指南**：TMS 五步操作引导、术语表、临沂本地物流特色讲解

## 车辆配置（10 辆）

| 车型 | 数量 | 载重 | 用途 |
|---|---|---|---|
| 重型干线货车（重卡） | 4 | 10–30t | 临沂→济南/青岛/烟台长途干线，走高速 |
| 中型厢式货车 | 2 | 5–10t | 省内中短途城际 |
| 冷链冷藏车 | 2 | 5–8t | 半岛海鲜/生鲜专线 |
| 平板挂车 | 1 | 20–35t | 建材/钢材/大件，多走国道 |
| 城配微型货车 | 1 | 0.5–1.5t | 临沂市区批发市场送货 |

## 技术栈

- 纯前端单文件 HTML，无构建工具，无后端
- SVG 绘制山东省 16 地市真实行政边界 + 高速/国道路网
- ECharts 5（jsDelivr CDN）绘制趋势图
- 响应式布局：桌面端侧边栏导航，手机端顶部横向导航
- 地图支持鼠标滚轮缩放、拖动平移、手机双指捏合缩放、单指拖动
- 时间流速可调：1× / 2× / 5× / 10× / 20× / 50×
- 每次打开恢复初始演示数据，不同电脑打开即还原

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装依赖、无需联网（除 ECharts CDN）。

Windows 用户可双击 `启动TMS.bat` 自动打开。
